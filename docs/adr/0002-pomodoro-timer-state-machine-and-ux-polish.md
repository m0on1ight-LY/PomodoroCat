# ADR 0002: 番茄钟状态机严密闭环与多维视觉交互优化

## 状态
已采纳 (Accepted) - 2026-08-19

## 背景与痛点
在真机实测中发现以下交互与视觉缺陷：
1. **计时控制状态机混乱**：跳过专注进入短休后，计时器标题显示“短时休息”，但主操作按钮文案仍然硬编码为“开始专注”；在计时进行中缺乏即时“放弃/重置”入口。
2. **底部导航栏 M3 药丸遮罩突兀**：Material 3 `NavigationBarItem` 默认给选中项绘制高对比矩形色块底纹，破坏了图标和界面的精致感。
3. **猫咪图鉴缺乏辨识度**：猫舍列表卡片使用通用 emoji 占位，导致 5 种猫咪毛色、面具与眼睛特征无法被用户感知。
4. **主页猫咪点击矩形波纹**：点击猫咪抚摸时，系统默认绘制了正方形的 Material 点击波纹。

## 决策方案

### 1. 番茄钟状态机与控制栏（State Machine Refactoring）
- **空闲态（IDLE）**：支持在「🍅 专注」、「☕ 短休」、「🌴 长休」三大模式之间自由切换；主按钮动态渲染为「开始专注」或「开始休息」。
- **运行态（RUNNING）**：提供清晰的三段式控制：主按钮「暂停」、次按钮「放弃/重置」、辅助「跳过本轮」。
- **暂停态（PAUSED）**：提供「继续专注/继续休息」与「重置」。

### 2. 底部导航栏去除遮罩（Clean Aesthetic Navigation）
- 将 `indicatorColor` 设置为 `Color.Transparent`，通过 `primary` 主色强调色、加粗字重与平滑过渡展示当前选中 Tab。

### 3. 猫咪图鉴微缩矢量渲染（Procedural Miniature Cat Avatar）
- 为每个图鉴卡片创建独立 Canvas 过程化渲染组件 `MiniCatAvatar(skinSpec)`，实时绘制橘斑、暹罗面具、三花斑纹、奶牛倒V和英短纯蓝。
- 注入个性化品种标签（如「🍊 元气干饭王」、「☕ 学霸黑脸包」、「🎩 帅气小警长」）。

### 4. 猫咪无框交互响应（Indication-Free Interaction）
- 在 `CatCompanion` 的点击监听中配置 `indication = null`，彻底消除正方形点击杂边，配合跳动粒子和专属台词达成极致治愈感。
