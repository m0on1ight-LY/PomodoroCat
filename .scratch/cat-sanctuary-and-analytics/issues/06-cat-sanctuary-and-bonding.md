# 06: Cat Sanctuary, Feeding, Bonding and Milestone Badges

**What to build:** A `SanctuaryScreen` allowing users to browse the 5 cat companions, spend DriedFish to unlock locked breeds, feed their active cat (10 fish = +10 EXP) to progress BondLevel from Lv.1 to Lv.5, interact via touch to trigger petting animations/dialogues, and display an achievement badge showcase wall.

**Blocked by:** 01 (Room Data Infrastructure and Entities), 03 (Post-Focus Settlement Dialog and DriedFish Economy Engine), 05 (Procedural Multi-Skin Vector Cat Engine)

**Status:** resolved

- [x] Interactive Cat Sanctuary gallery card carousel or grid displaying all 5 cat breeds with lock/unlock status and unlock costs.
- [x] Feeding action button deducting 10 DriedFish and animating feed particles, increasing cat Affection EXP and triggering level-up transitions (Lv.1 to Lv.5).
- [x] BondLevel progress bar and current status perks displayed (Lv.1 Shy -> Lv.2 Friendly -> Lv.3 Clingy -> Lv.4 Playful -> Lv.5 Soulmate).
- [x] Tapping the cat companion in sanctuary triggers dynamic pet reaction animations and thought bubble dialogues.
- [x] Achievement Badge Wall showcasing unlocked and locked milestone badges with unlock progress.
