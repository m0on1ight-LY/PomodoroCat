# 04: Analytics Dashboard and Focus Diary Timeline

**What to build:** An `AnalyticsScreen` displaying multi-dimensional productivity insights with Day/Week/Month/All-time tabs, key metric cards (total focus time, sessions completed, dried fish earned), tag distribution charts, a streak calendar heatmap, and a reverse-chronological focus diary stream.

**Blocked by:** 01 (Room Data Infrastructure and Entities), 03 (Post-Focus Settlement Dialog and DriedFish Economy Engine)

**Status:** resolved

- [x] Top tab switcher supporting Day, Week, Month, and All-time aggregation views.
- [x] Metric cards showing total focus duration, completed pomodoro count, and dried fish earned in the selected period.
- [x] Pure Canvas / Compose donut chart showing focus time percentage distribution across TaskTags.
- [x] Streak calendar / contribution heatmap highlighting active focus days.
- [x] Chronological focus diary timeline rendering past sessions with timestamp, tag badge, star rating, and user reflection note.
